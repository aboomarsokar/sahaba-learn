# PCB — نسخة الطالب

صفحةٌ تعليمية تفاعلية (فيزياء · كيمياء · أحياء) بدروسٍ واختباراتٍ ونسبة إنجاز، تعمل بلا إنترنت.

## البنية

| المسار | ما فيه |
|---|---|
| `index.html` | الصفحة كلُّها: التنسيق والكود والمحتوى (الدروس `CHEM`… والأسئلة `LQ` والحلول `SOL`) |
| `images/` | الصور، ويُشار إليها في الصفحة بـ `images/اسم.jpg` |
| `videos/` | مقاطع الفيديو، ويُشار إليها في `var VID` |
| `build.py` | يدمج الصور والفيديو في ملفٍّ واحد |

## المعاينة

افتح `index.html` من خادمٍ محليّ (المسارات النسبية لا تعمل بفتح الملف مباشرة):

```bash
python3 -m http.server 3090
```

ثم `http://localhost:3090`. وإن فُعّلت GitHub Pages فالرابط: `https://aboomarsokar.github.io/pcb-student/`

## نسخة الطالب (ملفٌّ واحد)

```bash
python3 build.py
```

يُنتج `dist/pcb-student.html` (~16 م.ب) يُرسل على واتساب ويعمل بلا إنترنت.
