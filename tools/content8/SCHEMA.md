# محتوى العلوم للصف الثامن (فيزياء/كيمياء/أحياء)

كلّ مادةٍ ملفّ JSON واحد: `tools/content8/<physics|chemistry|biology>.json`. المصدر الوحيد: رزمة «العلوم والحياة» للثامن (PDF).
يتحقّق منه `python3 tools/content8/check.py <الملف>`، ويركّبه `tools/make_pcb8.py` في `<المادة>/8/`.

```json
{
 "subject": "biology",
 "units": [
  {"title": "عنوان الوحدة", "icon": "🔬", "sym": "μm",
   "lessons": [
    {"t": "عنوان الدرس",
     "e": ["# عنوان قسم", "نص عادي", "- نقطة", "! تنبيه/فائدة", "|عمود1|عمود2", "|خلية|خلية"],
     "q": ["- سؤال مراجعة 1؟"],
     "quiz": [{"l":0,"k":"n","q":"نص السؤال؟","o":["أ","ب","ج","د"],"a":0}],
     "hints": {"نص السؤال تماماً": "تلميح من سطرين يوجّه التفكير دون كشف الجواب"}}
   ],
   "unit_quiz": [[0,"سؤال؟",["أ","ب","ج","د"],1]]}
 ],
 "sems": [[0,1],[2]],
 "bank": [{"q":"سؤال سريع؟","o":["أ","ب","ج","د"],"a":2}]
}
```

## القواعد
- `e`: صيغة الشرح: سطر يبدأ بـ `# ` عنوان قسمٍ (٢–٦ أقسام لكلّ درس)، `- ` نقطة، `! ` تنبيه، `|` صفّ جدول (الصفّ الأول ترويسة)، وغير ذلك فقرة. كلّها مأخوذة من الرزمة (تعريفات، خطوات الأنشطة ونتائجها، قوانين، أمثلة محلولة).
- `q`: ٣–٥ أسئلة مراجعة مفتوحة تبدأ بـ `- `.
- `quiz`: ٢٤ سؤال اختيار من متعدد لكلّ درس: ٨ لكلّ مستوى `l`=0 (مستكشف: تذكّر مباشر)، `l`=1 (متقدّم: فهم وتطبيق)، `l`=2 (متميّز: استنتاج وحسابات وسيناريوهات). `k`: `"n"` نظري أو `"p"` عملي (موقف/تجربة/مسألة)، والمستويان ١ و٢ يغلب عليهما `p`. أربعة خيارات دائماً و`a` فهرس الصحيح (٠–٣) ووزّع مواضع الصحيح عشوائياً (لا تجعلها كلّها 0).
- `hints`: تلميح لسؤال واحدٍ على الأقل من كلّ مستوى (المفتاح نصّ السؤال حرفياً).
- `unit_quiz`: ٩–١٢ سؤالاً لكلّ وحدة بصيغة `[مستوى, سؤال, [٤ خيارات], فهرس الصحيح]`.
- `sems`: توزيع فهارس الوحدات على الفصلين.
- `bank`: ١٥–٢٠ سؤال «اختبار سريع» عامّ للمادة (٤ خيارات).
- الأرقام والرموز العلمية بصيغتها الصحيحة (Unicode: H₂O، م/ث²، x²). لا تخترع حقائق خارج الرزمة؛ الأسئلة تُبنى على ما في الرزمة.
- اللغة: عربية فصحى مبسّطة.
