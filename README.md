# مدارس الصحابة — المنصّة التعليمية

دروسٌ تفاعلية وأنشطة واختبارات للصفوف من الأول إلى العاشر: الرياضيات، والعلوم العامة، واللغة الإنجليزية، وما يُضاف لاحقاً.

| المادة | الجاهز |
|---|---|
| الرياضيات | الصف العاشر (`math/10`) |
| العلوم العامة | الصف العاشر (`science/10`) |
| اللغة الإنجليزية | قريباً |

## التشغيل محلياً

```bash
python3 tools/build_site.py
python3 -m http.server 8000 --directory _site
```

ثم `http://localhost:8000`.

## النشر

كلّ دفعٍ إلى `main` يشغّل `.github/workflows/pages.yml`، فيبني الموقع وينشره على GitHub Pages.

طريقة إضافة مادةٍ أو صفّ في [CLAUDE.md](CLAUDE.md).
